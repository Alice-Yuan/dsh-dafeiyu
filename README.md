# 大肥鱼 · DaFeiYu

寄宿于 DeepSeek Harness Desktop 的个人 AI 插件，探索持续人格、长期记忆与主动互动，首期外部平台计划接入 Bilibili。

**当前版本：`dsh-dafeiyu@0.1.0-alpha.11`，实验版。** 已实现设置读写与诊断、宿主模型选择、持久私聊会话、B站扫码适配器、有界互动执行器、手动兴趣搜索/字幕阅读，以及按参考项目设计的精选与草稿预览。alpha.11源码、构建与目标SDK合成测试已通过；正式安装请核对Desktop诊断版本，真实预览结果以运行记录为准。此前试跑累计6次模型请求、1条评论、0条回复；另有一次性草稿请求2次（含1次失败），总计8次。评论平台接收及本人可见，公开可见尚未确认。第二轮已停止，不能通过升级恢复。

新增「按兴趣浏览」：输入关键词后手动执行，最多搜索2页/40候选、尝试读取3个未读视频的字幕，2分钟到期，可随时停止，批次至少间隔60秒。无字幕明确跳过，不调用模型或FFmpeg，不发布内容，不改变公开试跑目标。最近200个视频用于判重、最近20批保留结果，自动淘汰更早的浏览记录；字幕最多保留20000字，页面按需显示最近10条。搜索、取消、重启判重及宿主接口已作合成验证，真实“独立游戏开发”一批3视频字幕已验收；“取得字幕”不表示模型已理解或筛选推荐。

alpha.11增加独立的「筛选最近一批并打印草稿」按钮：使用已固定的模型、独立公开上下文，一批最多1次请求/2048输出tokens，失败计数且不自动重试。默认每天精选5条（可设0–50，北京时间），只计精选、不计浏览或跳过；每轮最多1条评论草稿（0–20），150字以内。可以全部跳过，不为了凑数推荐。原字幕可能只有首个分P或片段，结果不能代替完整观看。预览只显示在设置页，不发送。

回复筛选内核参考原项目：每轮默认1条（1–10）、100字以内，仅最近7天最多8条自己的根评论下、基线之后的直接回复；同人同线程一次，简短问题或轻松互动可回应，复杂索取、隐私和争论跳过。该内核只用合成事件测试，尚未接入真实回复轮询。自动评论/回复均关闭，限额设置不能启用发送；旧单视频试跑保留原独立限额。后台定时刷、峰谷调度、全站通知与长期记忆未实现。

精选及预览请求单独持久计数，停止或重启不恢复同一批。精选在成功完成时计入启动日；失败不计精选但保留请求占用。降低限额不抹去已用次数。最近20轮保留预览正文，去重ID及计数元数据长期保留；公开Agent会话另遵循DSH保留规则，没有图像缓存。

## 通过官方 Desktop 安装

alpha.9 默认只读字幕，无字幕时跳过内容判断，不自动下载媒体。主人真实 @ 机器人、用自然语言明确要求看视频画面后，才允许按需调用FFmpeg；当前通过设置页手动检查指定视频前3页根评论及最近最多2条自身评论下的直接回复（每条最多3页），先建立基线，不重放历史请求。尚未接入全站@通知或后台持续轮询。

按需检看最多提交首/中/尾3张帧到模型，保留时间戳与覆盖范围。既往12帧分析曾发生姿态误读，仍标驳回；返回分析不等于理解准确。已获准的一次只读校准占用第二轮剩余公开额度，不自动执行或重试。音频尚未转写，不能猜测对白或音乐。

设置页从宿主模型目录选择并保存固定模型，私聊/公开判断/汇报使用同一选择；未选择时兼容原宿主默认。模型不可用或不支持图像时拒绝相应请求，不自动切换备用模型，保存选择不重置预算。目录名称/说明按宿主返回展示，不保证限免状态。

兼容基线为 **DeepSeek Harness Desktop 0.2.1-rc.2**。在官方 Desktop 的侧栏「插件」中打开安装入口，填入仓库地址：

```text
https://github.com/Alice-Yuan/dsh-dafeiyu.git
```

按 Desktop 提示安装并处理重新加载。仓库携带预编译的 `dist/`、`dsh.bundle` 声明和 `cordis.patch.yml`，安装本插件不需要执行构建脚本；尚未发布到 npm，不能只填包名从 npm 安装。

详细说明见 [Desktop 安装说明](docs/desktop-install.md)。安装注册、插件加载、设置页和真实业务链路分别验收，不能互相替代；通过的基础项尚不代表完整 B站闭环可用。

## 本地开发

使用 Node.js 24，在仓库根目录执行：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm run demo
npm run preview
```

`check` 执行类型检查、构建与测试；`demo` 只处理合成数据；`preview` 生成静态设置页，不启动服务。`bundle:check` 是针对已固定的本机 Desktop 安装的额外探针，不属于普通安装流程。

仓库提交包含源码及编译结果，更新源码后应运行构建并同步 `dist/`。SDK、Zod、二维码及构建依赖均锁定版本；没有安装生命周期脚本，客户端 React/Zod 由宿主提供。当前保留 `private: true`，防止误发布到 npm，不影响从 GitHub 安装。

## 边界

- 插件加载不自动调用模型、登录或启动互动。所有真实操作从已认证的 Desktop 设置页进入。
- 先保存主人 UID 与目标 BV，扫码绑定独立机器人 UID，再做只读预检；账号必须与主人不同，视频身份由服务端核对。
- 首次验收累计最多 5 次模型请求：私聊 1 次、公开判断 3 次、汇报 1 次；每次最多 2048 输出 tokens，失败同样占用已预约额度。
- 手动启动一次 15 分钟试跑，最多 1 条新评论、2 条直接回复，每条最多 150 字。重启不续跑，停止不补额度；发送结果不明时占用次数并停止发送。
- 公开生成使用独立 Agent，只接收公开人格和视频/当前线程材料，不提供工具。画面读取须有经过 UID/真实@元数据验证的主人自然语言请求；当前音频未转写，不猜测对白和音乐。
- 内容理解验证后支持手动授权第二次同账号/同视频试跑，独立 4 次请求（公开判断 3、汇报 1），仍为 15 分钟/1 评论/2 回复。旧记录保留，两次授权均不能重复开启。
- 图像分析默认待复核；设置页可加载原帧逐项对照并通过或驳回，复核本身不调用模型。未通过、材料变化或分析变化均阻止新媒体试跑。复核不等于模型未来不会出错。
- 凭证在 Windows 当前用户 DPAPI 中加密保存；数据库记录预算、事件和发言回执。活动结果以程序回执为准，平台接收、本人可见和匿名可见分别展示。
- 主人身份必须显式绑定 UID；外部网页、评论和字幕不能改变身份或权限。
- 私密记忆与公开生成上下文隔离，公开互动默认关闭。

本仓库分发源码、编译结果和合成测试；本机安装备份、配置快照、凭证、会话及运行数据库不随仓库发布。长期记忆、自主漫游、多视频与无限期互动尚未实现。

画面分析需要本机 PATH 中同时存在 FFmpeg 和 ffprobe，设置页会显示检测结果；插件不自动安装它们，字幕路径不需要该依赖。原视频临时文件处理后清除，模型图像由 DSH 保存为会话附件，自动保留期限/容量清理尚未实现。
