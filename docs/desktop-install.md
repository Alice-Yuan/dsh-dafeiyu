# 官方 Desktop 安装与试跑

插件名称：**大肥鱼（DaFeiYu）**；包名：`dsh-dafeiyu`；版本：`0.1.0-alpha.9`。兼容基线为 Windows DeepSeek Harness Desktop **0.2.1-rc.2**。

## 安装

1. 在官方 Desktop 侧栏「插件」的安装入口输入 `https://github.com/Alice-Yuan/dsh-dafeiyu.git`。
2. 按官方提示安装、重新加载；核对包名、版本和中文说明。仓库含预编译 `dist/` 和 bundle，无需执行本插件的构建脚本，未发布 npm 包。
3. 打开插件详情的“大肥鱼”设置。先检查实际宿主状态及诊断版本，再保存配置并重新读取核对。

可使用 `https://github.com/Alice-Yuan/dsh-dafeiyu.git#<commit>` 固定已审查提交。安装失败时保留错误和现有配置，不重复点击，不升级其他插件，不降低发布年龄/构建脚本等包管理策略。既有插件的 manifest 与锁文件不一致可能阻断整个安装事务，需要单独处理。

## 首次验收

1. 保存明确的主人 UID、目标 BV 号和公开人格。公开人格只能包含可以公开的信息；诊断标记不进入公开生成。
2. 使用专用机器人账号扫码，在手机端确认。凭证不会显示；设置页只显示读取到的机器人 UID。主人 UID 与机器人 UID 不得相同。
3. 运行只读预检，核对账号、视频标题/BV、字幕有无和基线评论数。首次最多读 3 页，每页 20 条，不重放历史消息；评论区明确只读、禁用输入或缺少可写状态时拒绝启动。
4. 发送一次私聊，验证“大肥鱼 · 主人会话”及默认模型。总预算是 5 次请求，每次输出上限 2048 tokens；私聊、公开判断和汇报分别最多 1、3、1 次。失败/重试也不能免费补额。
5. 手动点击“启动一次 15 分钟试跑”。此按钮允许在选定视频公开发言，最多 1 条评论、2 条回复，单条最多 150 字；只回复本次自身评论下直接回复机器人的新消息。每 60 秒检查，最多 15 轮，期限优先。
6. 可随时停止。停止、到期、卸载和重启都不能继续发送或重新开启同一预算。没有新回复即“未触发”，不会制造互动。15 分钟是活动上限；首次判断选择跳过时可提前结束，不为等待满时长而追加请求。

正常结束可用预留的 1 次请求汇报；取消时只投递程序回执，不再调用模型。回执包含来源和评论链接，分别标明平台接收、本人可见、匿名读取可见或结果不明。发送后断线且没有评论 ID 时保持 unknown，不能通过再次发送来验证；“仅核对发送回执”只能复查已有 ID 的结果。

## 数据与限制

无字幕时从实际视频流采样最多 12 帧，覆盖不超过 10 分钟的视频，下载上限 64 MiB。需要本机 PATH 中已有 `ffmpeg` 和同目录 `ffprobe`；本机验收版本为 7.1.1，不随插件下载或安装。DSH 默认模型必须明确支持图像；不支持时显示 `DEFAULT_MODEL_VISION_UNAVAILABLE`，不会静默丢弃图片。设置页“读取并理解视频”使用现有公开判断预算 1 次，不启动评论、不重置旧试跑。可点击“立即停止”取消读取/理解。

理解结果只代表所列时间戳的画面采样；音频未转写。原视频临时文件完成后删除，采样图像由 DSH 附件存储随会话保留。

分析默认标为“待复核”。点击“加载原帧对照（不调用模型）”，核对带时间戳的实际画面；描述错误时驳回，不能据此启动新试跑。只有原帧核对通过且账号、BV/aid/cid、实际材料及分析版本仍一致才能启动媒体试跑。复核备注仅保存在本地，不进入公开生成上下文；通过或驳回都不重置预算和试跑。

图像请求在当前默认模型明确声明支持 low 时采用该推理档位，模型路由与 2048 输出上限不变。输出额度耗尽显示 `MODEL_OUTPUT_LIMIT`；失败占用请求，只有原始预算尚有余量时才能手动重试理解，成功后不能重复分析。不自动重试或新增额度。

本版提供一次独立的第二轮手动试跑入口，前提是第一轮已完成且视频理解经原帧复核通过；账号/主人/视频必须与首轮一致。点击该入口明确启用新的 15 分钟/1 评论/2 回复授权，新增 4 次请求（3 次公开判断、1 次汇报）；保留旧请求和回执，不把首轮未用次数转入新轮次，不支持第三轮或自动续期。

- 凭证存于当前 Desktop profile 的 `data/dsh-dafeiyu/bilibili.dpapi`，由 Windows 当前用户 DPAPI 加密；配置与 SQLite 不保存 Cookie。移除本地凭证不代表平台已撤销该登录。
- `pilot.sqlite` 保存主人绑定、预算、事件 ID、发送状态与程序回执；没有自动清理或重置按钮，避免误续跑。聊天和公开生成会话由 DSH 持久化。保留期限/清理另行由主人决定。
- 平台接口可能变化或触发风控；此时停止并显示错误，不尝试绕过。媒体读取失败时不能以标题或封面替代视频观看。
- 私聊会话正在被另一宿主控制器占用时可能显示 `SESSION_OPEN_IN_NATIVE_CHAT`；程序回执仍可写入已存在会话，模型汇报失败会明确显示。
- 已在 Desktop 0.2.1-rc.2 完成官方 Git 安装、配置恢复、真实默认模型私聊、扫码登录与视频预检。一次手动试跑因无字幕、简介和评论而选择跳过，主人会话汇报和程序回执已持久化，累计 3/5 次请求、0 条发送。公开请求的空工具、2048 上限与独立上下文已核对；发送、直接回复、平台可见性与完整 15 分钟轮询未触发。自动故障测试另行验证预算、取消和恢复，不能替代这些真实分支验收。
