# 官方 Desktop 安装说明

插件名称：**大肥鱼（DaFeiYu）**；包名：`dsh-dafeiyu`；版本：`0.0.1-mock.2`。

插件描述：大肥鱼：寄宿于 DeepSeek Harness Desktop 的个人 AI 插件，探索持续人格、长期记忆与主动互动。当前为本地模拟原型，尚未接通真实模型和 B站。

## 安装

1. 使用 DeepSeek Harness Desktop 0.2.1-rc.2，在侧栏「插件」进入安装入口。
2. 输入 `https://github.com/Alice-Yuan/dsh-dafeiyu.git`，按官方界面的检查、安装和重新加载提示操作。
3. 在插件列表核对包名、版本和中文描述；检查插件详情是否显示“大肥鱼”的模拟设置页。安装报错时保留错误信息，不反复点击安装。

仓库包含预编译文件，安装无需执行本插件的构建脚本。需要固定版本时可使用 `https://github.com/Alice-Yuan/dsh-dafeiyu.git#<commit>`，将占位符替换为实际提交 SHA。默认仓库地址安装默认分支的当前内容；尚未发布 npm 包。

## 验收边界

安装入口和中文描述字段依据已安装的 0.2.1-rc.2 官方实现确认；bundle 声明、编译入口及模拟逻辑分别验证。完整 Desktop GUI 的加载、设置页实际渲染、配置读取和真实主人会话仍待验收。设置页目前为只读模拟骨架，不能证明真实配置功能已经完成。

安装不会接入真实模型或 B站，也不会发送评论。真实模型、账号接入和公开操作分别按授权启用。
